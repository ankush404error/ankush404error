# Install this animated profile README

1. Download and extract this bundle.
2. Open your GitHub repository named exactly `ankush404error` (the profile repository).
3. Replace its `README.md` with this bundle's `README.md`, then upload the `assets/`, `scripts/`, `data/`, and `.github/workflows/` folders.
4. Commit to the `main` branch.
5. Open **Actions → Refresh profile contribution art → Run workflow** once. Allow Actions to write to the repository if GitHub asks.
6. The contribution SVG updates daily after the workflow succeeds.

The portrait is a monochrome ASCII rendering of the photo you provided. It is stored as an SVG; the original photo is not included in the bundle.

Note: third-party typing/stat cards in README are hosted services and may occasionally be unavailable. The portrait, banner, info card, and contribution heatmap are local SVG assets. Contribution scraping depends on GitHub's public HTML markup; if GitHub changes it, the workflow may need a small parser update.
