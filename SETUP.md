# BLACKSITE — Cinematic GitHub Profile

This version uses a cinematic cyber-operations image and a custom animated dossier strip rather than a generic badge-heavy banner.

## Install
1. Download and extract the ZIP.
2. Open your profile README repository: `ankush404error/ankush404error`.
3. Replace `README.md`.
4. Upload the `assets/` folder too, preserving the paths.
5. Commit to `main` and view your profile.

## Design notes
- `assets/blacksite-hero.png`: custom cinematic hero art based on the photo you provided.
- `assets/dossier-strip.svg`: locally hosted animated operator/status strip.
- Live typing and GitHub stats use third-party image endpoints and can occasionally be unavailable.
- Project details are summarized from previously discussed work. Confirm public status and edit anything you do not want displayed before publishing.
- This is a GitHub README, not a full interactive web app; GitHub does not allow arbitrary JavaScript in README content.
